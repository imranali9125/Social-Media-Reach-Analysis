# Social-Media-Reach-Analysis

1. Project Overview
Social Media Reach Analysis is a data analytics project that analyzes the performance of social media posts across different platforms such as Instagram, Facebook, and Twitter.

The main objective is to understand how many people view posts, which platform gets the highest reach, which content performs best, and how engagement changes over time.
2. Technologies Used
- Python
- Pandas – Data cleaning and analysis
- NumPy – Numerical calculations
- Matplotlib – Data visualization
- Seaborn – Statistical visualization
- Jupyter Notebook / Google Colab
3. Project Objectives
1. Analyze total social media reach.
2. Compare reach across different platforms.
3. Identify the best-performing posts.
4. Analyze likes, comments, and shares.
5. Find the relationship between reach and engagement.
6. Visualize monthly social media performance.
